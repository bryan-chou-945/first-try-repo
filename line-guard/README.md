# LINE 防傳錯小幫手

適用於 **Windows 電腦版 LINE** 的小程式，在你送出訊息前提醒「現在是傳給誰」，減少傳錯對象的機會。

## 它會做什麼

| 情況 | 行為 |
|---|---|
| 切換到另一個聊天室 | 左上角短暫顯示「目前聊天室：XXX」 |
| 換聊天室後的第一則訊息 | 跳出確認視窗，顯示聊天室名稱 |
| 同一個聊天室超過 2 分鐘沒傳訊息 | 再確認一次 |
| 聊天室名稱包含「公司、老闆、主管、客戶、工作」 | 每一則都要確認 |
| 同一個聊天室連續聊天 | 不打擾，直接送出 |

確認視窗的**預設選項是「否」**：習慣性多按一次 Enter 只會取消，要按 **Y** 才會送出。

- `Shift + Enter`：照常換行
- `Ctrl + Alt + L`：暫停或恢復本程式

## 安裝方式

1. 下載並安裝 [AutoHotkey v2](https://www.autohotkey.com/)。
2. 下載這個資料夾裡的 `line_guard.ahk`。
3. 雙擊 `line_guard.ahk` 執行。右下角工作列出現綠色 **H** 圖示就代表正在執行。
4. （選用）開機自動執行：按 `Win + R`，輸入 `shell:startup`，把 `line_guard.ahk` 的捷徑放進去。

## 自訂設定

用記事本打開 `line_guard.ahk`，修改最上面的「設定區」：

```ahk
SAFE_SECONDS := 120                                   ; 連續聊天幾秒內不重複確認
ALWAYS_CONFIRM := ["公司", "老闆", "主管", "客戶", "工作"]  ; 每則都要確認的關鍵字
```

存檔後，在工作列的 H 圖示上按右鍵，選「Reload Script」就會套用。

## 注意事項

- **只支援電腦版。** 手機版 LINE 不允許其他 App 攔截或檢查要送出的訊息，任何程式都做不到。手機上請使用聊天室背景、修改好友顯示名稱等方法。
- **聊天室名稱是從視窗標題讀取的。** 如果你的 LINE 把聊天室開在獨立視窗，標題通常就是聊天室名稱。如果所有聊天都在 LINE 主視窗裡，標題可能只顯示「LINE」，這時確認視窗無法顯示對象名稱，只會提醒你看畫面再送出。
- **使用注音等輸入法時**，如果你習慣用 Enter 選字，換聊天室後的第一次 Enter 也會跳出確認視窗。按 Y 會完成選字，之後在同一個聊天室就不會再跳出。
- 在 LINE 的搜尋框按 Enter 也可能觸發確認，按 Y 即可。
